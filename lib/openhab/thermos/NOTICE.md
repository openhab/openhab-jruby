# Thermos attribution and license

Thermos is substantially derived from [Spring](https://github.com/rails/spring),
the Rails application preloader. Its command dispatch, binstub generation,
client/server lifecycle, environment handling, and process management closely
follow Spring. Thermos adapts that design to openHAB/Karaf and uses a fresh
JRuby ScriptEngine for each command instead of forking a Rails application.
